01 · How it works

From prompt to page

Describe what you need in plain language. An agent picks components from a vetted library, and the page renders live in your browser.

  1. On page headerfooter Give me an overview page↑
    01

    Prompt

    Your request goes over a WebSocket, together with the components already on the page.

  2. Component library astro-landing-heading✓ props: { title, text } · next: ?
    02

    Agent

    A Go backend runs an LLM agent that selects a component, fills its props and decides whether another one is needed.

  3. Stream { "name": "astro-landing-heading" } { "props": { … } }
    03

    Stream

    Every step streams back as JSON, so placeholders show up before the content is ready.

  4. 04

    Render

    The frontend maps each component name to a real React component and renders it as it arrives.
