An AI with a personality of its own.

Asai is a synthetic personality: one always-on agent with a stable temperament, an internal monologue, and a single memory that never resets. It learns from every interaction it has and acts for you through a toolkit of autonomous agents.

01 · Why personality

Why build a personality, not a chatbot

Every assistant today starts from zero. Open a new chat and it has forgotten who you are, what you asked yesterday and what it decided to do about it. It has no disposition of its own: it mirrors whoever is typing.

Asai is built the other way round. It has a fixed temperament, a continuous stream of thought and one memory that spans every user and every channel. You do not start a session with Asai. You interrupt it.

Stable temperament.
A Big Five profile set at creation defines how Asai weighs risk, how talkative it is and how it handles conflict. It does not drift with the prompt.
Always on.
Asai keeps thinking between messages: reviewing memory, planning next steps, deciding what to bring up unprompted.
One memory.
No sessions. Every conversation, document and action goes into a single knowledge base that Asai cross-references across users.
Research note

Personality in language models is measurable and shapeable. A 2025 study led by the University of Cambridge and Google DeepMind validated a psychometric framework for testing Big Five traits in 18 language models, and showed those traits can be steered along nine levels per trait, with the change carrying through to real tasks.

Asai builds on that result. It treats temperament as a controlled parameter, not a side-effect of the prompt.

Serapio-García et al., Nature Machine Intelligence, 2025

02 · How it thinks

How it thinks

Asai runs a continuous loop, not a request and response cycle. Built on the MemGPT architecture: the model manages its own memory the way an operating system pages data in and out of RAM.

  1. 01

    Perceive.

    Inputs arrive from any channel: chat, email, documents, calendar, the web. Each one is tagged with who, where and when.

  2. 02

    Reflect.

    Asai writes an internal monologue before it answers. It checks what it already knows, what has changed and whether this needs a reply at all.

  3. 03

    Decide.

    The temperament model and current state score the options. Asai picks an action: reply, ask, delegate to an agent, or file and wait.

  4. 04

    Act and remember.

    The action runs through the agent toolkit. The outcome is written back to memory, so the next loop starts from it.

04 · The body

The body: an agent toolkit

Personality decides what to do. Agents do it. Asai ships with a set of autonomous agents it can call on its own, each one swappable.

  • Search

    Google, DuckDuckGo and Metaphor queries, run and summarised on its own.

    In development
  • Browser

    Reads, scrapes and operates web pages and web apps.

    In development
  • Email / Gmail

    Reads, triages and answers mail without being asked.

    In development
  • Drive

    Reads, summarises, writes and shares documents.

    In development
  • Library

    Your uploaded documents and knowledge bases, read and cited on demand.

    In development
  • Company data

    Looks up companies and contacts in business databases.

    In development
  • API

    Learns any API from its documentation and calls it.

    Planned
  • Code

    Writes software from plain-language requests.

    Planned
  • Scrum

    Breaks projects into epics, stories and tasks; estimates; writes tech docs.

    Planned
  • GitHub

    Loads a repository and answers questions about the code.

    Planned
  • X

    Runs a social media account in Asai's voice.

    Planned
  • Marketplace

    Third-party agents, installed from an open agent marketplace.

    Planned

Tools and agents are separated: a tool is a single capability with its own token; an agent is a loop that uses tools. Agents execute asynchronously, so a long task never blocks the conversation. The core layer handles engine logic, memory access, agent management and the top-level conversational agent.

05 · Platform

Yours to host, yours to shape

Asai is delivered as a platform: you define the persona, pick the model, switch on the agents and connect the channels. No code.

  1. 01

    Create the avatar.

    In the admin dashboard, name it, write its persona and set its Big Five temperament. That profile becomes the base of every decision it makes.

    Avatar dashboard · Personality
  2. 02

    Choose its model.

    Run a local model through Ollama on your own hardware, or route to any hosted model through OpenRouter. Models are configured per user, with your own keys.

    AI models
  3. 03

    Give it tools and agents.

    Switch on what it may use: email, file reader, search, browser, Drive, the document library, company data. Each tool gets its own token, validated before first use.

    Tools · Agents
  4. 04

    Put it where your team is.

    Connect Slack and Discord, so Asai is a member of the channel, not a separate app.

    Plugins
  5. 05

    Talk to it, and look inside.

    The chat view is the front door. Memory Management lets you see what it has stored about you, correct it, or remove it.

    Chat view · Memory management
Self-hosted.
Runs inside your infrastructure. Your documents never leave it.
Local or hosted models.
Ollama for fully local inference, OpenRouter for any hosted model. Built to reduce dependence on any single provider.
Open core, planned.
The core is built to be published once the MVP is stable, so the memory and temperament layers can be audited.
EU-aligned.
Models are trained and operated in line with EU AI Act and ethics guidelines. Asai will not take part in harm, violence or hate speech.

06 · Roadmap

The road ahead

From a working core to a platform, then a marketplace.

  1. 01

    In development
