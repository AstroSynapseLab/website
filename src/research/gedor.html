Research 04EU-hosted inference

Open-weight models, hosted in the EU.

Gedor is a platform for running language models in Europe: one OpenAI-compatible endpoint over a curated catalog of general, coding and embedding models, with managed vector databases alongside. Dedicated infrastructure and ready-made agents follow.

01 · Why EU-hosted

Your prompts stay under EU law

Most hosted LLM APIs run on infrastructure owned by companies outside the EU, so the data they process can fall under non-EU law as well as European law.

For teams handling financial, health, legal or public-sector data, that can rule them out before the first prompt. Gedor runs on GPUs in an EU data center, under EU law: GDPR and the EU AI Act.

EU-resident compute.
Inference and storage stay in an EU data center.
Open weights.
A curated catalog of open-weight models. No lock-in to one vendor's model.
Drop-in API.
Existing OpenAI-compatible clients work unchanged. Point them at a new endpoint.

02 · Architecture

How a request travels

From your code to a GPU and back, every hop after the gateway runs inside the same EU data center.

  1. 01

    Gateway.

    One OpenAI-compatible endpoint. It checks the API key, applies per-tenant rate limits and meters usage before anything reaches a model.

  2. 02

    Orchestration.

    Kubernetes with KServe places each model on the cluster, scales idle models to zero and rolls out new versions as canaries.

  3. 03

    Inference.

    vLLM serves the models, with PagedAttention and continuous batching to keep throughput high.

  4. 04

    GPU nodes.

    The compute itself, in an EU data center. The response goes back the way the request came.

04 · Retrieval

Your documents, next to your model

Start a managed vector database, upload files, and they are split into chunks, turned into embeddings and stored in a collection. Query it from the playground or over the API with the same key.

05 · Platform

Three layers, one platform

The pipeline from model to vector store to agent is meant to be something a team can set up without an ML department.

01 · ModelsLaunching first

Models as a service.

The hosted catalog behind one OpenAI-compatible API, with managed vector databases next to it.

02 · InfrastructurePlanned

Dedicated EU compute.

Dedicated GPU capacity for your own models. Bring a model and its deployment spec, and reach it through the same API.

03 · AgentsPlanned

Agents as a service.

Ready-to-use agents for documents, web research, email and calendar, and long-form research. Already have one? Bring your own agent and run it on EU infrastructure.
